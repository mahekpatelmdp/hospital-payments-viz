🏥 Hospital Payments Data Visualization
An interactive Tableau dashboard analyzing heart attack hospital payment data across the United States built as a college data visualization project.

📊 Project Overview
This project explores average Medicare hospital payments for heart attack treatments across U.S. states and providers. Using a dataset of 54+ marks across all 50 states, the dashboards uncover geographic payment disparities and highlight which hospitals and states rank above or below the national average.

🔍 Key Questions Explored

How do average heart attack hospital payments vary across U.S. states?
Which hospitals appear most frequently and receive the highest payments?
How do state-level payments compare to the national average?


💡 Key Findings

California and Florida have the highest total average payments among all states
Good Samaritan Hospital and St. Joseph Hospital rank highest among individual providers, each appearing 6 times in the dataset
The stacked bar chart view shows most states fall below the national average, with CA, FL, and IL as clear outliers
The TreeMap highlights state and city-level concentration, with CA, TX, and FL dominating by provider count
